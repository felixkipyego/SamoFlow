# constraint for those unreachable splits, unsatisfiable no matter how
# the pin's own marker was scoped (confirmed live, three attempts).
#
# --overrides forces this version UNCONDITIONALLY across the whole
# resolution, bypassing marker-conflict checking entirely -- the correct
# mechanism for this class of problem (see Makefile's own UV_COMPILE
# comment for when to reach for this vs. -c/--constraints instead).
