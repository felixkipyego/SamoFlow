# Electronics Returns

## Return Window for Electronics

Electronics (headphones, speakers, chargers, and small gadgets) have a shorter 14 day return window from delivery, not the standard 30 day window other categories get. The item must include all original cables and accessories it shipped with.

## Opened Electronics

An opened electronics item can still be returned within the 14 day window as long as it is not physically damaged. We test returned electronics before issuing a refund, which can add a few extra days to the refund timeline.

## Non-Returnable Electronics

Earbuds and other items that touch the ear or skin cannot be returned once the packaging seal is broken, for hygiene reasons, unless the item is defective.
